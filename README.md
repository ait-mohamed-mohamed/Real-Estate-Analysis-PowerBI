#  Real Estate Market Analysis with Power BI

##  Project Overview

This project focuses on analyzing the real estate market using **Microsoft Power BI**. It aims to explore property prices, identify market trends, and transform raw data into meaningful insights through interactive dashboards and data visualizations.

##  Objectives

- Analyze real estate market trends.
- Explore property prices and their variations.
- Identify key factors influencing property prices.
- Build interactive dashboards to support data-driven decision-making.

##  Tools & Technologies

- **Power BI Desktop** — Data visualization and interactive dashboards.
- **Power Query** — Data cleaning and transformation.
- **DAX** — Calculations and analytical measures.
- **Data Analytics** — Exploratory analysis and insight generation.

##  Project Workflow

1. **Data Collection:** Import the real estate dataset.
2. **Data Cleaning:** Handle missing values, inconsistencies, and data quality issues.
3. **Data Transformation:** Prepare and structure the data using Power Query.
4. **Data Analysis:** Explore property prices and market indicators.
5. **Data Visualization:** Develop interactive Power BI dashboards.
6. **Insights:** Identify trends and patterns in the real estate market.

##  Key Analysis Areas

- Property price distribution.
- Price comparisons across locations.
- Real estate market trends.
- Relationships between property characteristics and prices.

##  How to Use

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` file in Power BI Desktop.
4. Explore the interactive dashboards and visualizations.
